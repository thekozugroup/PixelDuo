# Dependencies

Dependency versions are pinned in `build.gradle.kts` and `app/build.gradle.kts`.

PixelDuo uses Kotlin, AndroidX Activity, Compose UI and Material 3 Expressive. JUnit is used only for local tests. The Lucide fold icon is included as a vector resource under the ISC license. The adapted glass shader and its upstream MIT notices are retained.

There are no vendored client binaries or Shizuku, HiddenApiBypass, Samsung firmware, network or analytics dependencies. See `THIRD_PARTY_NOTICES.md` for attribution.
